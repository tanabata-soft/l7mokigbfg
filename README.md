# デジタルCDエンジン（テンプレート）

デジタルCDシリーズ（デジタルCDアルバム／デジタルシングルCD）の**エンジンと制作手順の正本**です。新作は、このリポジトリをコピーして作ります。

- このリポジトリは**非公開**で、公開はしません。GitHub Pages も有効化しません。
- 作品の公開先は、配布用 Organization `tanabata-soft` 配下の公開リポジトリ（名前は作品名を含まないランダムな文字列）です。**テンプレート（作る場所）と作品（届ける場所）は役割が違います。**
- 収録されている雛形の作品（「テンプレートシングル」、シングル形態・2曲・10秒の仮音源）は実在の作品ではありません。そのまま `npm run verify` / `npm run test:e2e` / `npm run shots` が通る状態にしてあり、新作では `src/album/` の中身を実在の曲・絵・文章に置き換えます。

## 最初に読むもの

- [docs/START-HERE.md](./docs/START-HERE.md) — 新作の作り方の入口（流れ・分担・採番・既存作品の一覧）
- [docs/PRODUCTION.md](./docs/PRODUCTION.md) — 制作手順と運用ルール
- [docs/SINGLE.md](./docs/SINGLE.md) — デジタルシングルCDの仕様
- [CLAUDE.md](./CLAUDE.md) — アプリの技術方針

## 構成

- `src/`（`src/album/` 以外）: エンジン。画面・再生・同期歌詞・Service Worker・初回一括ダウンロードなど。作品ごとに触らない
- `src/album/`: **作品データ一式（差し替え対象）**
  - `album.ts`: 題名・カタログ番号・形（`layout: 'album' | 'single'`）・ノート／ライナーの文面・奥付
  - `tracks.ts`: 曲目・解説（正本）
  - `sync.ts`: 歌詞の同期データ（生成物。歌詞のない曲は空配列）
  - `media.ts`: 曲ごとの画像・音源の対応
  - `assets/`: 画像と音源（mp4）。`jacket.jpg` / `back.jpg` / `bg.jpg` と `trackNN.jpg` / `trackNN.mp4` の固定スロット
- `docs/`: 仕様・手順・引き継ぎ書式・ジャケット様式の調査（DESIGN-STUDY）
- `e2e/` / `tests/`: 画面テストと単体テスト（同梱の期待値は雛形作品＝シングル形態用）

## メンテナンスの決まり

- エンジン側の改良は、まずこのリポジトリに入れます（公開済みの作品へは自動では効きません。必要な作品へは個別に移植し、各作品の `docs/HANDOVER.md` に記録します）。
- 依存関係は作品リポジトリと揃えます。Dependabot PR は当面放置の方針です（作品側の決定に倣う）。
